# ✨ Features

- Stored info on death:
    - Related player
    - Death message
    - Death and respawn locations
    - Death inventory
    - Death time
    - XP, hunger, and saturation on death
    - Player ping on death
    - Server TPS on death
- JSON Storage
- Easy Death Refunding
    - Replace inventory with death inventory
    - Refund XP
    - Refund Saturation
    - Teleport back to death location
- GUI navigation
- Death broadcasting
    - In server chat
    - In Discord, through a webhook

# ⚙️ Requirements

- [LuckPerms](https://luckperms.net) (or any permission plugin)
- [NexusCore](https://modrinth.com/plugin/nexuscore)
- Java 25+
- Minecraft 1.18+

## 🧩 Optional integrations

- [SkinsRestorer](https://modrinth.com/plugin/skinsrestorer): displays restored player skins in GUIs.
- [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/): enables SkinsRestorer texture placeholders
  in Discord webhook player heads.
